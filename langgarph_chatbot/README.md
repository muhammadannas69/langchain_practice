# 🤖 LangGraph Chatbot

A simple AI chatbot built using **LangGraph, LangChain, Google Gemini, and Streamlit**.

This project demonstrates how to create a chatbot with conversation memory using LangGraph's `InMemorySaver`.

## 🚀 Features

* 💬 Interactive chat interface using Streamlit
* 🧠 Google Gemini AI model
* 🔗 LangGraph workflow
* 💾 Conversation memory using `InMemorySaver`
* 🆔 Thread-based conversation using `thread_id`
* 📋 Chat history maintained in Streamlit session state
* ⚙️ System message for controlling chatbot behavior

## 🛠️ Technologies Used

* Python
* LangChain
* LangGraph
* Google Gemini
* Streamlit
* Pydantic
* python-dotenv
